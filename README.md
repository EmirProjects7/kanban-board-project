# Kanban Board

A Kanban board web application built with React and TS, featuring drag-and-drop task management across columns.

> **Note:** This is a learning project, currently under active
> development. More features are planned. A full README with
> setup instructions will follow once the project is further along.


## Tech Stack

- React + TypeScript
- Vite
- dnd-kit

## Getting Started

```bash
npm install
npm run dev
```
